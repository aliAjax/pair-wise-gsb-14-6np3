# 油品价格维护 · 价格牌下发确认闭环

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

每笔调价选择 **站点、油品、目标价、批次**，派发后为 **价格牌 + 每把同油品油枪** 各生成一条确认项：

- **同终端同批次唯一**：一条终端在一个批次里只能有一条确认项，重复派发被拦截；不同站点可挂同一批次。
- **回报约束**：终端离线、重复回报、缺确认人的回报一律不生效，确认进度保持不变，尝试记录在「未生效回报记录」中。
- **部分进度保留**：刷新页面后批次、每把枪的确认进度、终端在线状态一致恢复（localStorage 持久化）。
- **全部回报才生效**：一笔调价的全部终端确认后才更新挂牌价并写入价格历史；批次内所有调价均完成后批次冻结，冻结批次不能再挂新调价。
- **撤回**：仅限未生效调价，需填写原因，撤回后释放全部派发项（同终端同批次可重新派发），挂牌价不变、不写历史。
- **已生效不可撤回**：只能新建一笔调价；价格历史保留旧价 → 新价、调发起人、价格牌与每把油枪的确认人和时间，全程可追溯。

## 分层结构

```
src/price/
  types.ts    领域类型（站点 / 终端 / 调价 / 批次 / 确认项 / 价格历史）
  rules.ts    纯业务规则：派发、回报、撤回、上下线、冻结、挂牌价推导（无框架依赖）
  seed.ts     站点油枪主数据与初始挂牌价
  demo.ts     用规则函数构造的自洽演示数据（历史冻结批次 + 部分进度批次 + 离线拒绝）
  storage.ts  存储层：版本化 localStorage 读写 / 重置，不含业务判断
  store.ts    Pinia 状态层：页面动作 → 规则层 → 落盘 + 提示
src/components/
  AdjustForm.vue   新建调价（新建批次 / 挂未冻结批次、旧价预览、确认项数量预览）
  BatchList.vue    当前挂牌价 + 按批次分组的调价卡片 + 已冻结/已撤回折叠区
  AdjustCard.vue   进度条、逐终端回报模拟、在线开关、重复回报、撤回
  PriceHistory.vue 旧价 → 新价与全部确认人可追溯
  RejectedLog.vue  离线 / 重复回报等未生效尝试留痕
```

规则层为纯函数（输入状态、输出新状态），派发唯一性、离线/重复幂等、冻结判定、撤回释放等规则均集中在 `rules.ts`，页面与存储不包含业务判断。
